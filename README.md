# alvaPortfolio

Live site: [alvaportfolio.vercel.app](https://alvaportfolio.vercel.app)

<img width="960" height="601" alt="LandingpagePortfolio" src="https://github.com/user-attachments/assets/f075e6e2-0924-4d1e-892b-d95ee1abb1b4" />

Personal portfolio website built with Next.js, React, TypeScript, and Tailwind CSS.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
